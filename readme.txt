# Онлайн кинотеатр
Этот сайт был создан для поиска и просмотра фильмов.

## Функции
- Возможность использования поиска 
- Сайт имеет фильтр жанров
- Есть возможность авторизации и регистрации
- Присутствует добавление фильмов в имеющиеся папки и редактор профиля

## Технологии 
- Python 
- PostgreSQL
- HTML
- CSS

## Источники 
- Фронтенд: [HTML5 UP - Prologue](https://html5up.net/prologue)
